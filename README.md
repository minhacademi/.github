# minhacademi/.github

Organization-wide files of Cademí on GitHub.

- [`profile/README.md`](profile/README.md) is the profile shown at [github.com/minhacademi](https://github.com/minhacademi).
- [`SECURITY.md`](SECURITY.md), [`SUPPORT.md`](SUPPORT.md), and [`.github/ISSUE_TEMPLATE/config.yml`](.github/ISSUE_TEMPLATE/config.yml) are the defaults for every public repository of the organization that does not have its own.

To report a bug or ask a question about the Cademí MCP, the CLI, the API, or webhooks, go to [minhacademi/developers](https://github.com/minhacademi/developers). Documentation is at [cademi.dev](https://cademi.dev).
