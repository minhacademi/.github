# Getting help

- **Documentation**: guides and reference for the Cademí MCP, the `cademi` CLI, the API v3, and webhooks are at [cademi.dev](https://cademi.dev).
- **Bugs and feature requests**: open an issue in [minhacademi/developers](https://github.com/minhacademi/developers/issues/new/choose), which takes reports for the MCP, the CLI, the API, and webhooks. With the CLI installed, `cademi bug` opens one with your version filled in.
- **Questions and ideas**: ask in [developers discussions](https://github.com/minhacademi/developers/discussions).
- **Security vulnerabilities**: report them privately, as described in the [security policy](https://github.com/minhacademi/.github/blob/main/SECURITY.md). Never in a public issue.
- **Your account, plan, or data**: these belong to Cademí support, not to a public repository.
