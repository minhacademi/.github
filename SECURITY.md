# Security policy

This policy applies to every public repository of Cademí that does not have its own.

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

Report them privately through GitHub: open a [private vulnerability report](https://github.com/minhacademi/developers/security/advisories/new) in the `minhacademi/developers` repository. Include the repository and version affected, the steps to reproduce, and the `request_id` of an API call when you have one. Do not include real credentials or personal data.

If a credential may have been exposed, revoke it in your Cademí dashboard right away. If a webhook signing secret may have been exposed, rotate it.

The full policy for the Cademí API, Cademí MCP, and the `cademi` CLI is in [minhacademi/developers](https://github.com/minhacademi/developers/security/policy).
